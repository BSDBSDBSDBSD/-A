# שיחות שלא נענו - מסך מרוכז

אפליקציה למכשירי מקשים (שיאומי Qin 1s, F21, F21 Pro, F22 Pro ודומיהם):
אחרי שיחה שלא נענתה קופץ מסך אחד עם **כל** השיחות שלא נענו, גם כשהמכשיר נעול.

## מה יש בה
- מסך אחד לכל השיחות; כמה שיחות מאותו מספר מוצגות בשורה אחת עם מונה (×3)
- מופיע מעל מסך הנעילה ומדליק את המסך
- שם איש הקשר, המספר ושעת השיחה
- OK או המקש הירוק = חיוג חוזר; החזקה או מקש תפריט = התקשר / שלח הודעה / הסר
- "נקה הכל" מסמן הכל כמטופל; "סגור" משאיר את השיחות לפעם הבאה
- שיחות חסומות ושיחות שנדחו ידנית לא מוצגות
- אפשרות להסתיר את האייקון (חזרה להגדרות: לחייג `*#*#6477#*#*`)
- בלי תלויות חיצוניות, Java בלבד

## בנייה
דחיפה ל-GitHub מפעילה את `.github/workflows/build.yml`, וה-APK מופיע תחת Actions → Artifacts.
לבנייה מקומית עם Android SDK: `gradle assembleRelease`.

## התקנה
1. להתקין את ה-APK ולפתוח את האפליקציה
2. ללחוץ על כפתורי 1-4 לפי הסדר עד שכל השורות מסומנות ✓
3. "הצג את המסך עכשיו" לבדיקה
